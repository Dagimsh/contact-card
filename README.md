# Contact Card Application

A modern, responsive React web application for showcasing contact cards, singer directory profiles, and social media links. Built with React 19 and Vite.

## 🌟 Features

- **Interactive Contact Cards**: Clean and accessible card components displaying user profiles, names, emails, phone numbers, and avatar images.
- **Responsive Layout**: Designed for seamless viewing across desktop, tablet, and mobile screens.
- **Fast Performance**: Powered by Vite for lightning-fast Hot Module Replacement (HMR) and optimized production builds.

## 🚀 Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **Linter**: Oxlint
- **Styling**: Modular Vanilla CSS

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- `npm`

### Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/contact-card.git
   ```

2. Navigate into the project directory:
   ```bash
   cd contact-card
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
